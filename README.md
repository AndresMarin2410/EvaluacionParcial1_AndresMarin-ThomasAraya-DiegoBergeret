# Veterinaria San Marcos

Sitio web para la clínica veterinaria San Marcos (Rancagua), desarrollado para la Evaluación Parcial 1 de DSY1104 - Desarrollo Fullstack II. Incluye una tienda pública (inicio, productos/servicios, blog, contacto, registro e inicio de sesión) y un panel administrador (gestión de productos y usuarios).

## Cómo abrir el sitio

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en VS Code.
3. Haz clic derecho sobre `index.html` y selecciona **Open with Live Server** (o ábrelo directamente en tu navegador con doble clic).

No requiere instalación ni dependencias: es un proyecto de HTML, CSS y JavaScript puro (sin backend ni base de datos en esta etapa).
